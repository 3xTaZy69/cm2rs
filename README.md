### cm2rs - a library for serializing and deserializing savestrings from roblox game called "cm2". 
## 1. What can it do?

Export savestrings in different formats:
  1. default(from cm2)
  2. verilog
  3. json

Allow using lots of abstractions: adders, muxes, shifters, etc.

synthesize verilog(WIP)

create and modify game`s hardest mechanics: buildings

simulate circuits

## 2. Why cm2rs?

cm2rs has only one dependency - rand.

you could write your own library, but why start from zero?
